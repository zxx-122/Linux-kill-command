# 🐧 Linux 命令斩

> **看中文意思，输入英文命令。像背单词一样，把 Linux 命令真正变成你的。**

一款用「背单词」思路做的 Linux 命令练习 App：屏幕给中文意思，你凭记忆敲出对应命令。内置 **436 道题、30 个分类**，从 `ls` 到 `kubectl`，从常用参数到 Git/容器/数据库，还有**真实组合命令**（`sudo apt install`、`tar -czvf`、`git commit -m`…），一条条练到「已掌握」。

纯 HTML/CSS/JS 单文件应用，零依赖、数据全在本地，由 Capacitor 打包成 Android APK。手机浏览器打开 `index.html` 就能直接用。

---

## 🎯 设计理念

把「学命令」这件事拆成和背单词一样的循环：**出现 → 回忆 → 反馈 → 复习**。

- **出现**：看中文意思，回忆英文命令（打字模式是真功夫，选错了才长记性）
- **反馈**：答错立刻给出正确答案、英文全称记法、命令示例——错一次就学一次
- **复习**：错题自动进错题本，答对才「毕业」；练到全对，错题本会把你「放行」

数据只存在本地（`localStorage`），不上传、不注册、不联网。**连续打卡、称号晋级、每日目标**把坚持变成看得见的反馈——菜鸟到宗师，只差每天的十几题。

## ✨ 功能特性

### 三种答题方式
| 方式 | 说明 |
|------|------|
| ⌨️ 打字 | 看中文手敲命令，真实力。可用「提示」看首字母（扣 3 分） |
| 🔘 选择题 | 四选一，干扰项与题目同难度（基础题不会混入 `kubectl`） |
| 🃏 闪卡 | 看题面 → 翻答案 → 认识 / 不认识，快速刷词 |

### 练习控制
- **🌱 基础 / 🧠 进阶** 双难度：常用命令 + 参数速记 vs 运维、Git、容器、数据库
- 按分类筛题，收藏的命令优先出题
- 每轮 10 / 20 / 30 题可选
- **⏱️ 限时挑战**：每题 20 秒，超时算错，练的是手速和肌肉记忆
- **⬅ 上一题 / 下一题 ▶**：答完可回看上一题，答案停留 3 秒+可手动跳题，不再一晃而过

### 记忆闭环
- **错题本**：答错自动收录、按错误次数排序、答对毕业移除
- **每日目标 + 连续打卡**：自己定目标，坚持看得见
- **称号晋级**：累计得分 0 → 2000+，菜鸟 → 学徒 → 熟手 → 达人 → 大师 → 宗师
- 连对加分（3 连起）、首字母提示、超时/跳过/答错都有对应反馈文案

### 学习与统计
- **📖 命令大全**：按分类浏览、搜索命令/中文意思/英文全称，展开看释义、示例、**常用参数速查**、中英文发音
- **⌨️ 快捷键大全**：独立模块收录终端、nano/vim、tmux 等常用快捷键，支持搜索
- **📊 我的战绩**：最近 7 天打卡柱状图、分类掌握度、累计答题/正确率/得分、常错命令 Top5

### 体验细节
- 🔊 中文/英文语音发音（系统 TTS，自动匹配语音并预热）、答对答错音效、手机震动反馈；答题反馈里可直接「听一遍正确命令」
- 📘 内置「使用说明」弹窗，一眼看懂怎么用
- 🗑️ 战绩页一键「卸载本应用」：清除全部数据并尝试打开系统卸载界面
- 成绩一键分享；数据可导出到剪贴板
- 移动端优化：安全区适配、玻璃拟态卡片、无边框深色终端风

## 📱 安装

1. 下载 `Linux命令斩_v4.apk` 到手机
2. 允许「安装未知来源应用」，安装即可

> 不想装 APK？直接用手机浏览器打开 `index.html` 也一样能用。

## 💻 电脑上本地测试

应用是纯前端单文件，**没有后端**。双击 `启动测试.bat` 即可：

- 自动启动本地静态服务（优先 Python，其次 Node.js）
- 自动打开浏览器访问 `http://localhost:8000`
- 手机连同一 WiFi，访问电脑局域网 IP 也能在手机上测试

## 🛠️ 开发与构建

项目无框架、无构建工具依赖，一个 `index.html` 就是全部应用逻辑。

```
Linux-kill-command/
├── index.html                # 应用本体（单文件，可直接用）
├── Linux命令斩_v4.apk        # 打包好的 Android 安装包
├── 启动测试.bat              # 电脑上一键启动本地测试服务
├── README.md
└── extracted/                # 构建与测试工具
    ├── index.html            # 构建前源码
    ├── new_questions.js      # 题库扩充（Git / 容器 / 数据库等）
    ├── build.js              # 合并题库 → 生成新 index.html
    ├── parse_questions.js    # 题库提取到 questions.json
    ├── rebuild_apk.py        # 回填 index.html 进 APK、剔除旧签名
    ├── uber-apk-signer.jar   # APK 重签名
    ├── verify.js             # 静态校验（题库 / 语法 / 元素 / 锁）
    └── test_full.py 等       # Playwright 端到端测试 / UI 截图
```

### 构建流程

```bash
# 1) 合并题库并生成新的 index.html
node extracted/build.js

# 2) 静态校验
node extracted/verify.js

# 3) 回填 APK 并重新签名
python extracted/rebuild_apk.py
java -jar extracted/uber-apk-signer.jar --apks Linux命令斩_v4.apk
```

### 数据说明

所有学习数据（答题数、错题本、打卡、称号、目标、收藏）都保存在本机 `localStorage`，
键为 `linux-quiz-stats-v3`。没有账号、没有云端同步——想清零？只能手动重置。
